# جدول المدرسة — نسخة محلية للمدير

تطبيق محلي لإدارة الجدول المدرسي وتوليده تلقائياً. بلا إنترنت، بلا حسابات،
بلا دخول للمعلمين — كل شيء على جهازك.

## التشغيل

انقر نقراً مزدوجاً على **`تشغيل البرنامج.bat`**، أو من الطرفية:

```
python app.py
```

يفتح المتصفح تلقائياً على `http://127.0.0.1:5000`.
لإيقاف البرنامج: أغلق نافذة الطرفية السوداء (أو Ctrl+C).

## البيانات

كل شيء في ملف واحد: **`school.db`** بجانب البرنامج.
انسخه لتأخذ نسخة احتياطية كاملة، أو استعمل
«تنزيل نسخة احتياطية» من لوحة البداية (ملف JSON).

## ترتيب العمل

1. **الإعدادات** — اسم المدرسة، أيام الدوام، عدد الحصص، الفسحات، المواد الأساسية.
2. **المراحل والصفوف والشعب** — سطر لكل عنصر لإضافة عدة عناصر دفعة واحدة.
3. **المواد** — `الاسم | الاختصار` (الاختصار هو ما يظهر داخل خانة الجدول).
4. **المعلمون** — جدول قابل للتحرير: اضغط «إضافة صف جديد» ثم املأ الخانات
   مباشرة، واضغط «حفظ الكل» مرة واحدة. كل الخانات قابلة للتعديل في أي وقت،
   والصف الذي يُترك بلا اسم يُحذف عند الحفظ.
   ومن زر «عدم الإتاحة» تقفل خانات لا يُوضع فيها للمعلم شيء (قيد صارم).
5. **الإسناد** — لكل شعبة: المادة، المعلم، عدد الحصص أسبوعياً، وكم منها كتلة مزدوجة.
   وفي جدول «المطلوب مقابل الإسناد» تكتب المطلوب لكل شعبة بنفسك، ويُحسب
   **المُسند** من الإسنادات و**المُدرج** من الجدول العام تلقائياً.
6. **توليد الجدول** — فعّل القواعد التي تناسب مدرستك ثم ولّد.
7. **الجدول العام** — تعديل يدوي، تثبيت حصص، حل تلقائي للتعارضات، تصدير وطباعة.

## عدد الحصص لكل يوم

من **الإعدادات** تحدّد عدداً خاصاً لكل يوم — مثلاً الخميس 7 وبقية الأيام 8.
هذا العدد **ملزم في كل مكان**:

- المحرّك لا يولّد أي حصة بعده.
- الشبكة تعرض الخانات الزائدة مشطوبة ولا تقبل الضغط عليها.
- النقل أو الإضافة أو التبديل إلى خانة بعده **يُرفض** ويُعرض سببه.
- الحل التلقائي لا ينقل حصة إلى خانة بعده، وينبّهك إن كانت الوجهة يوماً مختصراً.

> إن قلّلت عدد حصص يوم بعد التوليد، ينبّهك البرنامج فوراً بعدد الحصص التي
> صارت خارج الدوام. إن لم تتسع بقية الأيام فلا مفرّ من تقليل نصاب مادة —
> والبرنامج يقول لك ذلك صراحةً بدل أن يحذف الحصص بصمت.

## التعارضات والحل التلقائي

في أعلى **الجدول العام** علامة حالة:

| العلامة | المعنى |
|---|---|
| ✓ أخضر | لا تعارضات ولا حصص فارغة |
| ؟ أصفر | لا تعارضات، لكن توجد خانات فارغة |
| ! أحمر (ينبض) | توجد تعارضات — اضغطها للحل التلقائي |

الحل التلقائي ينقل الحصص المتعارضة إلى خانات آمنة، ويُفضّل نفس اليوم ثم
الأقرب زمنياً، ويتجنّب الأيام المختصرة ما أمكن. ويعرض لك ما نُقل ومن أين
إلى أين، وما تعذّر ولماذا — لا شيء يتحرّك أو يختفي بصمت.

**التبديل** لا يتم إن نتج عنه تعارض مع حصة أخرى؛ يُرفض ويُعرض السبب.
عند تحديد حصة تُلوَّن الخانات الآمنة بالأخضر والحصص القابلة للتبديل بالأزرق.

**التوليد** لا يُعلَن ناجحاً إلا إذا لم تبقَ حصة بلا مكان ولا تعارض ولا خانة
فارغة. وإن بقي شيء، يعرضه مفصّلاً مع زر **تخطّي** للمتابعة كما هو.

## القيود

**صارمة (لا تُكسر أبداً):** تعارض المعلم، تعارض الشعبة، خانات عدم الإتاحة،
الحصص المثبّتة، طاقة المعمل، الفسحات، وحدود عدد الحصص لكل صف.

**ناعمة (كل واحدة قابلة للإطفاء):** توزيع المادة على أيام مختلفة، منع تتابع نفس
المادة، المواد الأساسية مبكراً، تقليل فراغات المعلم، توازن الحصص المبكرة والمتأخرة،
اليوم الذهبي، حدّ التكرار مع نفس الشعبة، أقصى حصص يومية ومتتالية، أقصى أيام
انتهاء متأخر.

> كل ما قلّلت القيود الناعمة، زادت فرصة التوليد الكامل.

إن تعذّر وضع حصة، يعرض البرنامج المادة والشعبة والمعلم **وسبب التعذّر** وما الذي
يفتح الجدول (تقليل نصاب مادة، أو رفع استثناء عن معلم، أو إعادة التوليد).

## التراجع

تُحفظ لقطة كاملة قبل كل عملية تغيّر الجدول: التوليد، التعديل اليدوي، المسح.
الاسترجاع نفسه يحفظ لقطة قبله — فحتى التراجع قابل للتراجع.
شاشة «سجل التوليد والتراجع» تحتفظ بآخر 40 لقطة لكل نسخة.

## النسخ

تقدر تنشئ عدة جداول مختلفة وتجرّبها وتبدّل بينها من أعلى الشاشة،
وتنسخ نسخة قائمة لتجرّب عليها دون المساس بالأصل.

## العرض والتصدير

لكل جدول ثلاثة اختيارات مستقلة، تنتقل معك بين الشاشة والطباعة والتصدير:

| الاختيار | القيمتان |
|---|---|
| المحتوى | حسب الفصول · حسب المعلمات |
| الشكل | جدول لكل فصل/معلمة · الجدول المجمّع (كل الفصول وأيام الأسبوع في جدول واحد) |
| الألوان | **ملوّن** (لون لكل مادة) · **بلا ألوان** (حدود ونصّ فقط) |

«بلا ألوان» للطباعة بالأبيض والأسود أو التصوير: تُزال ألوان المواد تماماً،
ويبقى التمييز بالحدود والنصّ الغامق. تبقى الفسحات والخانات خارج الدوام
برمادي فاتح لأنها بنية الجدول لا زينته.

- **PDF** — خط عربي مُشكَّل، ألوان المواد نفسها، وخانة توقيع اختيارية.
  المنفصل على A4 أفقي، والمجمّع على A3 أفقي.
- **Excel** — تنسيق RTL، ألوان المواد، الصف الأول والعمود الأول مجمّدان في المجمّع.
- **معاينة للطباعة** — اطبع من المتصفح أو احفظ PDF مباشرة.

عمود **المجموع** يظهر أول الجدول بجانب اسم الفصل أو المعلمة في كل الصيغ.

## الملفات

| الملف | الدور |
|---|---|
| `app.py` | خادم Flask وكل المسارات |
| `db.py` | مخطّط SQLite، الإعدادات، حدود الأيام، اللقطات |
| `solver.py` | محرّك التوليد: البناء، الإزاحة، التحسين |
| `edits.py` | التعديل اليدوي: التحقق، التبديل الآمن، الحل التلقائي، كشف الفراغات |
| `exports.py` | تصدير Excel وPDF |
| `templates/` | الواجهة (Jinja2، عربي RTL) |
| `static/` | التنسيق وجافاسكربت |
| `seed_demo.py` | بيانات تجريبية (**يمسح كل البيانات**) |
| `test_solver.py` | يولّد ويتحقّق أن أي قيد صارم لم يُكسر |
| `test_app.py` | يمرّ على كل الشاشات والمسارات |

## الاختبار

```
python seed_demo.py     # مدرسة متوسطة: 12 شعبة، 23 معلماً، 360 وحدة وضع
python test_solver.py   # يتحقّق من القيود الصارمة ويطبع مؤشرات الجودة
python test_app.py      # يتحقّق أن كل المسارات تعمل
python test_tweaks.py   # حدود الأيام، التحرير، الحل التلقائي، رفض التبديل
```
